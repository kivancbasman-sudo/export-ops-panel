# İhracat Operasyon Paneli

İhracat yapan firmalar için hava kargo, satış, paketleme listesi ve operasyon takip paneli.
Tek kullanıcılı, PWA çevrimdışı çalışma ve yerel dosya senkronizasyonu destekleyen operasyon aracıdır.
Gelişmiş navlun barem hesaplayıcı, Excel entegrasyonu ve sıfır veri kayıplı yedekleme sunar.
